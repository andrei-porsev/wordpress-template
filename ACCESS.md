# Доступы проекта

Агент читает этот файл **до** любого вопроса про хост, логин, SSH, SFTP, WP-CLI, сайт, админку, браузер, Figma, Claude Design, БД, Search Console и аналитику.
Что здесь заполнено (не прочерк) — **не переспрашивать**.
Пользователь дал новый доступ в чате — дописать сюда **в том же ходе** и в конфиг (`.vscode/ssh.json` / `sftp.json`). Не в конце задачи.
Пароли, ключи, токены в ответах **не цитировать**. В этом файле пароль не дублировать, если он уже в json: писать «в ssh.json» / «в sftp.json».

Прочерк = не выяснено. `нет` = доступа нет, не спрашивать снова.

Заполняется при **«старт проекта»** (skill `project-init` → `access.md`, блок F — все поля). Пустые прочерки после старта допустимы только если пользователь сказал «не знаю» / «потом».
