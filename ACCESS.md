# Доступы проекта

Агент читает этот файл **до** любого вопроса про хостинг, сервер, SSH, SFTP, WP-CLI, окружения, сайт, админку, браузер, макет, БД и аналитику.
Что здесь заполнено (не прочерк) — **не переспрашивать**.
Пользователь дал новый доступ в чате — дописать сюда **в том же ходе** и в конфиг (`.vscode/ssh.json` / `sftp.json`). Не в конце задачи.
Пароли, ключи, токены в ответах **не цитировать**. Пароль сервера — только в json; здесь писать «в ssh.json» / «в sftp.json».

Прочерк = не выяснено. `нет` = доступа нет, не спрашивать снова.
Заполняется при **«старт проекта»** (skill `project-init`, этапы 3 и 7). Поля `Публичный URL`, `Stage / dev URL`, `Режим заливки` читает хук заливки — названия не менять.
