# Иерархическая карта

- «Построй/обнови структуру» → skill `project-structure`.
- **`project-base/INDEX.md`** — пакет (тема / свой плагин) и слои (фронт / бэк).
- **INDEX пакета** — файл/модуль → за что отвечает; инструкции слоя — там же.
- **Детальный md** — функция/хук/класс → за что отвечает; лежит в `front/` или `back/`.
- Раскладка: тема → `project-base/themes/<slug>/{front,back}/`, плагин → `project-base/plugins/<slug>/{front,back}/`. Пакетов может быть несколько. Пустой слой не заводить.
- Русский язык; без копирования тел кода; чужие плагины не разбирать.
- Символы для карты — Grep, не парсер и не скрипт. Чтение исходников — rule `read-code`.
- Файл больше ~5 МБ в `project-base/` — предупредить и предложить облачную папку (ссылка в `ACCESS.md`); дампы БД сюда не класть — они остаются на сервере.
