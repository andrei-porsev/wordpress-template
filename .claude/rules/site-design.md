# Дизайн сайта: паспорт и границы

Паспорт — `project-base/design/system.md` (решение 041): цвета с назначением, типографика интерфейса и контента, отступы, компоненты, раскладки, движение, доступность, «не делать».
Откуда новый дизайн (Figma, Claude Design, план) — правило `design`; каркас и отступы — `markup-layout`, `scss-bem`.

## Перед вёрсткой

- Прочитать разделы паспорта, нужные задаче. Новый элемент собрать из его токенов и компонентов; похожий компонент есть — повторить его, а не придумывать.
- Определить зону: **интерфейс** (секции, карточки, кнопки, герой) или **контент** (текст записи из редактора). Значения — из своего раздела типографики.
- Паспорта нет — одной строкой предложить собрать (`project-init` → `design-system.md`); задачу можно делать по `theme.json` / `_variables.scss`, новые значения — по правилу ниже.

## Границы

- Новый цвет, шрифт, кегль, отступ, радиус, тень вне паспорта — **только с согласия** пользователя. После «да» — токен в тему, строка в паспорт.
- Стили контента — только внутри обёртки контента (FSE — `styles.blocks["core/post-content"]`). Голые `h2 { }`, `p { }` и `styles.elements` меняют и интерфейс.
- Заголовки интерфейса — размер по классу компонента, не по тегу: уровень `h2` / `h3` — по структуре страницы, вид — от класса.
- Компонент, вставленный в запись, сохраняет стили интерфейса; ритм контента на него не действует.
- Fluid — `scss-bem` → «Fluid» (решение 040).
- **Цвет в коде (решение 047):** hex — только в палитре `theme.json` (`color.palette`) и запасным значением. SCSS — `var(--wp--preset--color--<слаг>, <hex>)`;
  `theme.json` (`styles`) и разметка блоков — `var:preset|color|<слаг>` (CSS-переменную редактор не связывает с палитрой — «свой цвет»); так же шрифты, кегли, отступы — `var:preset|<тип>|<слаг>` (решение 049).
  Прозрачность: чёрный и белый — `rgb(0 0 0 / 20%)`, цвет палитры — `color-mix(in srgb, var(--wp--preset--color--<слаг>) 20%, transparent)`; `rgba( , , , )` — нет (stylelint).
  Слаг — с дефисом перед цифрой (`color-9`, `gold-2`): WordPress сам вставляет дефис в имя переменной, `color9` даст `--…--color-9`.

## После правки

- Новый типовой компонент или раскладка — строка в паспорт (класс, образец, состояния); изменился токен — поправить назначение.
- Правка стилей контента — проверка на записи со всеми элементами контента (`layout-check` → «Контент»).
