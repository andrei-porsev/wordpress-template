# Операции

Методы только из skill `project-ops`. Не подбирать WinSCP, lftp, scp, интерактивный ssh, ручной CSS.

`ssh-exec.mjs` — **отдельным вызовом Bash**, команда начинается с `node .claude/…` (без `cd … &&`: иначе не сработает `permissions.allow`),
после `--` ничего локального (`;`, `&&`, `| tail`, `2>&1`): охранник считает серверным всё после `--` и спросит подтверждение даже на чтение.
Объём вывода — флагами WP-CLI (`--fields=…`, `--posts_per_page=30`, `--number=…`, `--format=csv`), не конвейером: `wp … | head` — тоже подтверждение.

## Кто обновляет сервер

Человек сохранил в редакторе — `uploadOnSave` (ручная работа в Cursor), агент не дублирует.

Правки агента — по режиму `ACCESS.md` → «Заливка» (решение 012):

- `guarded-auto` (по умолчанию) и `stage-auto`: заливает хук после каждой правки в своей теме/плагине; сам `upload` не вызывать. Ошибку хука (откат) — исправить и править снова.
- `manual`: заливать только по команде («залей», «выложи», «задеплой») или после «да», список путей короткий.
- Короткий `manual` на задачу (`manual (задача «…», с <дата>; после выкатки — <режим>)`) — `WORKFLOW.md` → 2.4: правки копятся, выкатка — `deploy` разом, потом режим вернуть.
- Нет SSH/SFTP (host пустой) — заливки нет, режим фактически `manual`.

После заливки CSS / JS / шаблона — сброс кеша сайта (`ACCESS.md` → «Кеш сайта», `cache.md`), затем проверка в браузере.
Код ответа, заголовки, «открывается ли файл по URL» — `fetch( url, { method: 'HEAD' } )` в браузере на домене проекта (статус и заголовки, тело не читать);
`curl` / `wget` закрыты в `permissions.deny` — не пробовать (и в чужих скиллах вроде `wp-performance`).

Собранный CSS и `build/` создаёт Bash (compile / `npm run build`), хук их не видит: после сборки залей результат сам — `sftp-sync.mjs upload <пути>` (при `stage-auto` с флагом `--stage`; в `manual` — по команде или после «да»).

Вёрстка макета (`markup/`, `project.json` → `markup: true`) — только на stage, хук её не заливает: после проверенной правки — `node .claude/skills/project-ops/scripts/markup.mjs publish`
(изменённое против снимка stage, `--all` — всё; печатает ссылку на стартовую страницу и ответ сервера; в `manual` — по команде или после «да»), затем проверка в браузере.
Человек — `/markup`. На прод не выкатывается: в `sftp.json` прода `markup/` нет.

## Доступы

Сначала `ACCESS.md` (SSH, WP-CLI, URL сайта, админка, браузер, Figma). Заполнено или «нет» — не спрашивать снова.
При «старт проекта» поля собирает `project-init` → `access.md`, не откладывать.
Новый доступ от пользователя — в том же ходе в `ACCESS.md` и `ssh.json` / `sftp.json`. Пароль в чат не цитировать.

Прочие команды — `INDEX.md` → «Команды».
