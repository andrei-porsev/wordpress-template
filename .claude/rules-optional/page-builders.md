# Page builders

- Режим **кастомизации**, не миграции на FSE/classic «заодно».
- Правки: **child theme** (CSS/SCSS, `functions.php` хуки), их API/виджеты — не ядро билдера. Новый плагин не предлагай, пока это не отдельный переносимый функционал.
- Стили поверх билдера — в SCSS темы с достаточной специфичностью; избегай `!important` без нужды.
- Не предлагай перенос макетов Elementor→FSE (и обратно), пока пользователь явно не попросил.
- Woo + билдер: их Woo-виджеты/шаблоны первичны; PHP overrides Woo — только если виджеты не закрывают задачу.
- Skill: `page-builders`.
