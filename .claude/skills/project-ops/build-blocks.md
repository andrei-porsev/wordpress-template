# Сборка блоков

Правится только `src/`. `build/` — артефакт, руками не редактировать.

Человек может держать `npm run start`. Агент — разовую сборку.

## Команды

Каталог плагина (или темы), где лежит `package.json` со скриптом `build`:

```bash
npm run build
```

Рабочая папка — этот каталог, не корень WP. Нет `package.json` / нет `@wordpress/scripts` — не выдумывать webpack; смотреть `INDEX.md` → Сборка.

После успешной сборки `build/` готов локально. Сборка идёт через Bash, хук заливки её не видит: при `guarded-auto` / `stage-auto` залей результат сам (при `stage-auto` с `--stage`), при `manual` — по команде или «да» (`ssh.md`). Upload каталога `build/` — [sftp.md](sftp.md), не `src/` и не `node_modules/`. Если менялись `render.php` / `block.json` вне `build/` — те же пути в том же вопросе/команде.

## Когда

- После правки `src/**` блока.
- Пользователь просит «собери блоки», `npm run build`.
- В `INDEX.md` сборки нет — шаг пропустить, не ставить `@wordpress/scripts` без просьбы.
