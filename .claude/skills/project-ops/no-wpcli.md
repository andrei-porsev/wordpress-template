# Без WP-CLI — что делает человек

Когда SSH нет или оболочка без WP-CLI (`connect-check` → «WP-CLI: нет»). Агент даёт шаги, человек делает, агент проверяет результат (браузер, `sftp-sync`).
Каждый шаг — блоком «🖐 Сделать вручную» (`project-init` → `manual-steps.md`).

| Задача | С WP-CLI (агент, после «да») | Без WP-CLI (человек) | Проверка агентом |
|--------|------------------------------|----------------------|------------------|
| Бэкап БД | `ssh-exec.mjs dump` (→ `../claude-backup/<время>.sql`) | панель хостинга → бэкап; или плагин UpdraftPlus | человек: «готово», дата бэкапа |
| Замена домена | `wp search-replace … --dry-run`, затем без | плагин Better Search Replace: сначала «Run as dry run», потом по-настоящему | ссылки на сайте (браузер) |
| Пользователь агента | `wp user create claude-agent …` | Пользователи → Добавить: логин `claude-agent`, роль по `site.md`, сгенерировать пароль → в `ACCESS.md` | вход агента в браузере |
| Повысить / понизить роль | `wp user set-role claude-agent administrator` / `editor` | Пользователи → claude-agent → Роль | — |
| Удалить пользователя агента | `wp user delete claude-agent --reassign=<ID>` | Пользователи → удалить, записи — другому | вход отклонён |
| Плагин поставить / включить | `wp plugin install <slug> --activate` | Плагины → Добавить новый | список плагинов (`session-check`) |
| Запрет индексации stage | `wp option update blog_public 0` | Настройки → Чтение → «Попросить поисковые системы не индексировать» | `<meta name="robots" content="noindex">` в HTML |
| Сброс кеша | `wp cache flush`, плагин кеша | кнопка плагина кеша / панель хостинга | страница отдаёт новое |
| Постоянные ссылки | `wp rewrite flush` | Настройки → Постоянные ссылки → Сохранить | 404 пропали |
| Администраторы | `wp user list --role=administrator` | Пользователи → фильтр «Администратор» — список в чат | — |
| `siteurl` / `home` | `wp option get siteurl` | Настройки → Общие | — |

Свой код, стили, файлы темы — всегда через заливку (`sftp-sync`), не через админку (редактор файлов в админке не использовать).
