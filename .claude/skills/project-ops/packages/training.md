# Пакет «Обучение клиента» — инструкция и учётная запись

Результат: инструкция «как править сайт» под его стек и учётная запись клиента с ролью редактора (не администратора).

## 1. Учётная запись клиента

- Роль **Редактор** (страницы, записи, медиа, меню — по необходимости через плагин ролей). Администратор — только по прямому решению клиента, запись в `DECISIONS.md`.
- Создаёт человек или агент (`wp user create … --role=editor` после «да»); пароль клиенту — ссылкой «сбросить пароль» на его почту, не в чате и не в инструкции.

## 2. Инструкция

Документ для клиента (язык и тон — `brief.md`), скриншоты — агент в браузере на stage под ролью редактора (`project-base/screenshots/training/`), без личных данных.
Разделы — под стек сайта (`INDEX.md` → «Стек»):

| Стек | Что показать |
|------|--------------|
| FSE + паттерны | добавить страницу из паттерна, заменить текст и картинку, не трогать структуру секции; где меню (Внешний вид → Редактор → Навигация) |
| Блоки на ACF | поля блока справа, повторяющиеся элементы (добавить / убрать / порядок), что заблокировано и почему |
| Билдер (Elementor) | править только текст и картинки в готовых секциях, глобальные цвета и шрифты — не трогать, как откатить ревизию |
| Магазин | товар: цена, наличие, вариации, картинки; заказы: статусы, возврат |
| Всем | картинки: размер, `alt`; записи: рубрики, черновик / публикация; где формы и заявки; к кому обращаться, если сломалось |

Формат — `project-base/content/client-guide.md`; нужна отправка файлом — экспорт в PDF или документ (делает пользователь или агент по просьбе).

## 3. Сдача

- Клиент вошёл под своей учётной записью и выполнил одно действие по инструкции (добавил запись / поменял текст).
- Пользователь агента на проде удалён (`WORKFLOW.md` → 2.6).
