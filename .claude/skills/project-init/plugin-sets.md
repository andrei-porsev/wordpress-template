# Базовые наборы плагинов (этап 5)

Агент предлагает набор по виду сайта и географии, пользователь правит список. Установка — WP-CLI после «да» (меняет сайт → подтверждение и дамп).
Любимых плагинов у пользователя нет — набор составляет агент. Уже стоящее на существующем сайте не дублировать.

## Общее для всех

| Задача | Предложение | Заметка |
|--------|-------------|---------|
| SEO | Yoast SEO / Rank Math | один из двух, не оба |
| Безопасность | Wordfence | WAF и сканирование; на управляемом хостинге может быть свой |
| Бэкапы | UpdraftPlus (стандарт пользователя: и на stage, и у клиента) или средства хостинга | у хостинга есть — решает пользователь; на stage — расписание «вручную», 2 копии (`project-ops` → `stage.md`) |
| Кеш | по хостингу (LiteSpeed Cache, WP Rocket, свой кеш хостинга) | один слой кеша |
| Журнал действий | Simple History | на проде, где входит пользователь агента |

## По географии

| Посетители | Добавить |
|------------|----------|
| Европа | cookies и согласие — Complianz / CookieYes; шрифты и скрипты локально |
| США | согласие на cookies — по требованию клиента (CCPA для Калифорнии) |

## По виду сайта

| Вид | Добавить |
|-----|----------|
| Лендинг, корпоративный, портфолио | формы — по задаче (заявка, расчёт) |
| Магазин | WooCommerce, платёжный шлюз клиента; формы — по задаче |
| Блог или медиа | связанные записи, комментарии — по задаче |
| Каталог или сервис | поля (ACF), фильтры — по задаче |
| Несколько языков | Polylang / WPML |
| Локальный бизнес | разметка `LocalBusiness` (через SEO-плагин или тему) |
