# Паспорт дизайна — `project-base/design/system.md`

Заготовка — `project-base/_starter/design-system.md`. Правило работы с паспортом — `site-design`, решение 041.

## Когда

| Тип проекта | Когда собирать | По чему |
|-------------|----------------|---------|
| Существующий сайт (сопровождение, SEO, доработки, после другого разработчика) | после этапа 10, вместе с картой (`project-structure`) | живой сайт + код темы |
| Редизайн | старый паспорт → `system-before.md`; новый — после утверждения макета | утверждённый макет |
| Новый с дизайном / с готовым макетом | после утверждения (`approved.md`) | макет (Figma, Claude Design) |
| Без макета | план `frontend-design` после «да» сохраняется сюда, а не остаётся в чате | утверждённый план |

## Существующий сайт — по шагам

1. **Токены:** `theme.json` (`color.palette`, `typography.fontSizes`, `fontFamilies`, `spacing.spacingSizes`) и `_variables.scss` темы — слаги и переменные.
   Значения не копировать, только назначение.
2. **Живой сайт** (браузер, 375 и 1440; `layout-check` → «Окружение браузера»): главная, запись, архив, страница с формой. Вычисленные стили (`getComputedStyle`)
   ключевых элементов: заголовки героя, секций, карточек; текст; кнопки; ссылки; поля формы; контент записи — `h2`–`h4`, `p`, списки, цитата, подпись к картинке.
   Кегль и отступ — пара 375 → 1440. Обёртка контента — класс вокруг текста записи.
3. **Назначение цветов** — где какой цвет используется на сайте (кнопки, фоны секций, ссылки, акценты); неочевидное — вопросом пользователю.
4. **Компоненты** — повторяющиеся элементы с классом, образцом (адрес страницы) и состояниями (наведение, фокус).
   Меняются при прокрутке (прозрачная шапка → фиксированная, липкие панели, «наверх») — оба состояния: вычисленные стили и вырезка при `scrollY = 0`
   и после `scrollTo( 0, 800 )` с выключенными переходами, 375 и 1440; в паспорт — пара «вверху → при прокрутке» (фон, высота, цвет текста и логотипа, тень, переход).
5. **Отклонения** от правил шаблона (`markup-layout`, `scss-bem`, `fse-theme`, единицы 043: свой контейнер, `margin` между секциями, кегли без fluid, px,
   цвета литералами вне палитры, `!important`) — раздел «Отклонения», как есть, с номером решения или правилом.
   Цвет, который используется, но не стоит в палитре, — предложить токен (отдельной задачей).
6. **Доступность** — скилл `accessibility` (стек `quality`; не подключён — предложить подключить или проверить вручную): контраст пар «текст — фон»
   по WCAG, видимый фокус ссылок и кнопок, цели касания 44 × 44. Найденное — в раздел «Доступность»; исправление — отдельная задача после согласования с клиентом.
7. **Скриншоты-эталоны** — 5–8 вырезок компонентов и секций (JPEG, `project-base/design/screens/`), десктоп и мобильный.
8. Показать паспорт пользователю: назначения, «не делать», отклонения, доступность; цвета — плашками, шрифты — образцами (`site-design` → «Показ цветов и шрифтов пользователю»). Правки → «Утверждён: <дата>», коммит.

Вопросы — только о том, чего нет в коде и на сайте: назначение цветов, запреты, что считать образцом. Не спрашивать значения, которые можно измерить.
