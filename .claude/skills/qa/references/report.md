## Поля

- **Номер** — `Q<n>` по порядку в отчёте; в перепроверке — тот же номер.
- **Серьёзность** — одна из четырёх:
  - **blocker** — не работает главное: форма, оплата, оформление заказа, 5xx, страница не открывается, `noindex` на проде, чужие контакты на запуске;
  - **major** — видимая поломка: переполнение, налезание, обрезанный текст, неверный или пропущенный контент, нет перевода, другой шрифт или цвет бренда;
  - **minor** — отклонение от макета больше допуска, мелкие функциональные огрехи, опечатка, ошибка консоли без эффекта;
  - **cosmetic** — 1–2 px, оттенок, на грани допуска, кавычки и тире.
- **Направление** — буква A–R.
- **Где** — адрес, ширина, браузер, язык. Компонент на многих страницах — один баг, адреса списком.
- **Ожидалось** — источник: кадр макета, правило шаблона, файл типа, `QA.md`, здравый смысл («текст читается целиком»).
- **Факт** — что видно и, если ясно, почему (класс, свойство). Как исправить — не писать: это задача исправляющей сессии.
- **Статус:** открыт → исправлен (ставит исправляющая сессия) → подтверждён (ставит retest) / не баг (только с записью в `QA.md`, `SKILL.md` → п. 5).

## Клиенту — по просьбе

HTML-страница из того же отчёта: Artifact (`artifact-design`), приватная — ссылку пользователь отдаёт сам.
Без внутреннего: путей к файлам, классов, номеров решений, раздела «Человеку». Баги — на языке клиента (по умолчанию — язык сайта, спросить), со скриншотами (встроить в страницу), сгруппированы по страницам, серьёзность словами.
Статусы «не баг» не показывать.
