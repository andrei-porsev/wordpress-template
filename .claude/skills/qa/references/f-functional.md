# F — Функционал

## Где можно действовать (правило `safety`)

| Действие | Stage / локальный | Прод |
|----------|-------------------|------|
| Клик по меню, ссылкам, вкладкам, аккордеонам, слайдерам | да | да |
| Отправка формы | да, тестовые данные (`QA.md` → «Тестовая почта»), `QA` в теме / имени | **нет** — проверить валидацию без отправки; отправку делает человек |
| Заказ Woo | только тестовый режим оплаты (Stripe test, «Оплата при получении» на stage) | **нет** |
| Регистрация, подписка на рассылку | только stage | нет |

Выбор F в `/qa` — просьба на тестовые отправки на stage; на проде — только по отдельной прямой просьбе пользователя.

## Формы

1. Пустая отправка — ошибки показаны у полей, понятным текстом, на языке страницы; фокус на первом ошибочном поле.
2. Неверный e-mail, телефон — валидация.
3. Правильная отправка (stage) — сообщение об успехе, без перезагрузки на пустую страницу; повторная отправка не дублирует.
4. **Письмо дошло.** На сайте есть лог почты (WP Mail Logging, WP Mail SMTP с логом, Post SMTP) — последняя запись через WP-CLI, только чтение
   (`wp db query` по таблице лога с `--skip-column-names`, последние 3): получатель, тема, отправитель с домена сайта. Лога нет — спросить пользователя, пришло ли на тестовую почту; предложить плагин лога на stage (ставит человек или после «да»).
5. Защита от спама есть (reCAPTCHA / Turnstile / honeypot) — не обходить; мешает отправке — отметить в отчёте, отправку делает человек.

## Навигация и ссылки

- Меню: все пункты, подменю (наведение и клик, мобильное), активный пункт.
- Битые ссылки на страницах матрицы — `fetch( href, { method: 'HEAD' } )` по ссылкам своего домена в браузере (правило `ops`), статус ≥ 400 — баг; внешние — только список, без запросов к чужим сайтам в цикле.
- Якоря ведут к существующим `id`. `tel:` и `mailto:` — правильные номер и адрес.
- 404 — своя страница, код 404, есть путь назад. Поиск — находит существующую запись, пустой результат оформлен.

## Консоль и сеть

На каждой странице матрицы — ошибки консоли, 4xx / 5xx ресурсов сайта, смешанный контент (`http://` на `https://`).

## WooCommerce (если есть)

Каталог → товар (вариации, количество) → корзина (изменить, удалить, купон) → оформление (поля, доставка, налоги) → тестовая оплата (stage) → страница «Спасибо», письмо заказа (п. 4). Мини-корзина, счётчик.

## Серьёзность

Форма не отправляется, письмо не уходит, оформление заказа ломается, 5xx — **blocker**. Битая внутренняя ссылка, ошибка JS в консоли, ломающая элемент, — **major**. Ошибка консоли без видимого эффекта, плохой текст ошибки — **minor**.
