# C — Pixel perfect

Главное — **числа**: стили элемента на сайте против значений макета, с допусками из `QA.md` → «Допуски» (по умолчанию: размеры и отступы 2 px, кегль и интерлиньяж 1 px, цвет ΔE 3).
Наложение картинкой — вспомогательно: шрифтовое сглаживание и другой контент дают ложную разницу.

Уровень макета — `ACCESS.md` → «Дизайн»:

## Figma

1. Кадры: для каждой страницы матрицы — кадр макета на ширинах макета (обычно 375 и 1440). Соответствие «страница → кадр» — `QA.md` → «Матрица», колонка «Макет»; пусто — найти по `get_metadata` и записать.
2. Значения из макета — MCP Figma (`get_design_context`, `get_variable_defs`; скиллы `figma-use` / `figma-design-to-code`, если подключены): для каждого текстового стиля и ключевых блоков —
   `font-family`, `font-size`, `line-height`, `font-weight`, `letter-spacing`, `color`; у блоков — `width` / `max-width`, `padding`, `gap`, отступы между секциями, `border-radius`, фон.
3. Те же свойства на сайте — `browser_evaluate` с `getComputedStyle` по видимым элементам (правило `layout-check` → «Окружение браузера»), ширина окна = ширине кадра.
4. Сравнить: разница больше допуска — баг. Цвет — ΔE (CIE76 достаточно) между hex макета и `rgb()` сайта.
5. **Токены, а не элементы:** одно и то же значение неверно везде (кегль H2, цвет кнопки) — один баг на токен или компонент с адресами, не по экземпляру.
6. Наложение — `get_screenshot` кадра секции (масштаб 1) и снимок элемента той же секции на сайте при той же ширине (`browser_take_screenshot` с `ref`),
   `node .claude/skills/project-ops/scripts/shot-diff.mjs diff <макет> <сайт>`. «Несопоставимы» по высоте — сравнивать глазами, без числа.
   Большие области разницы при совпавших числах — порядок блоков, пропущенный элемент, другая картинка: смотреть и описывать.

## Картинки или PDF от клиента

Чисел нет. Ширина картинки макета → ширина окна (1440 / 375 или как в файле). Снимок страницы той же ширины, сравнение глазами по секциям: порядок, пропорции, выравнивание, отступы «на глаз» (замер по картинке — в px картинки).
Каждый такой баг — пометка «по картинке, ±4 px». Цвета — пипеткой не мерить: только явное несовпадение.

## Нет макета

C пропускается. Единство компонентов между страницами — правило `layout-check` → «Единство компонентов» (если выбран G или A — там).

## Не баг

- Отступления из `QA.md` → «Принятые отступления».
- Разница из-за контента: длиннее текст, другая картинка — это D, не C.
- Адаптив между ширинами макета: макета 768 нет — промежуточные ширины не сверяются с макетом (только A).
- Сглаживание шрифтов, субпиксели ≤ 1 px.

## Серьёзность

Другой шрифт, цвет бренда, пропущенный элемент, другой порядок блоков — **major**. Отклонение больше допуска — **minor**. На грани допуска (≤ допуск + 1 px) — **cosmetic**.
