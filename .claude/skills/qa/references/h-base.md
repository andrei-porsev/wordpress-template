# H — Доступность, скорость, SEO-база

Свои проверки не пишем — существующие скиллы и правила. QA собирает их итоги в баг-лист в своём формате, с серьёзностью.

| Что | Чем | Объём |
|-----|-----|-------|
| Доступность | скилл `accessibility` (если подключён), иначе базовое: `layout-check` → «Семантика», контраст текста ≥ 4.5:1 (крупный — 3:1), `alt`, подписи полей, порядок Tab | страницы матрицы |
| Скорость | `seo-unlighthouse` (все страницы матрицы, локально) или `core-web-vitals` / `seo-google` (CrUX — для прода с трафиком) | главная + по одной на шаблон |
| SEO-база | `seo-technical` по главной + список: один `h1`, `title` и `description` есть и уникальны, `canonical`, `robots` (stage — `noindex`, прод — нет), карта сайта, Open Graph | страницы матрицы |

Решения по SEO типа записи — `content-types/<тип>.md` → «SEO»: им следовать, не советам скилла.

## Серьёзность

Контраст ниже нормы у основного текста, форма без подписей, LCP > 4 с на мобильном, `noindex` на проде — **major** (на `launch` — `noindex` на проде **blocker**).
Нет `alt`, дубли `title`, CLS 0.1–0.25 — **minor**.
