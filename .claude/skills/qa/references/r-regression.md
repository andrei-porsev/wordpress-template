# R — Регрессия: до и после

Обновление плагинов, ядра, темы, PHP или переезд — ломает то, чего не трогали. R сравнивает снимки страниц матрицы до и после.

## Снимки «до»

Снимаются **до обновления** — иначе сравнивать не с чем:

- пользователь говорит «буду обновлять» / `/qa update` до обновления — сначала снимки «до», затем сказать «можно обновлять» и ждать;
- обновление уже прошло — взять последний набор `.claude/.state/reports/shots/qa-base/` (если свежее 30 дней и тот же адрес) и сказать, от какой даты сравнение;
  нет — R пропущен, строкой в отчёте; F и консоль — как обычно.

Набор: страницы матрицы × 375 и 1440, Chromium. Подготовка каждого снимка — правило `layout-check` → «Было → стало», п. 2 (картинки, шрифты, маска динамических зон из `QA.md` → «Исключения» и паспорта дизайна).
Файлы: `.claude/.state/reports/shots/qa-base/<страница>-<ширина>.png` (страница — slug или `home`). Плюс текстовый слепок на страницу:

```js
() => ( {
	title: document.title,
	h: [ ...document.querySelectorAll( 'h1,h2,h3' ) ].map( ( e ) => e.tagName + ' ' + e.textContent.trim().slice( 0, 60 ) ),
	links: document.querySelectorAll( 'a[href]' ).length,
	forms: document.querySelectorAll( 'form' ).length,
	scripts: [ ...document.scripts ].map( ( s ) => s.src.split( '?' )[ 0 ] ).filter( Boolean ),
	styles: [ ...document.querySelectorAll( 'link[rel="stylesheet"]' ) ].map( ( l ) => l.href.split( '?' )[ 0 ] ),
} )
```

— в `qa-base/<страница>.json` (Write).

## Снимки «после» и сравнение

Те же страницы, ширины, подготовка → `qa-<дата>-update/<страница>-<ширина>.png`, слепок → `<страница>.json`.
`node .claude/skills/project-ops/scripts/shot-diff.mjs diff .claude/.state/reports/shots/qa-base/<…>.png .claude/.state/reports/shots/qa-<дата>-update/<…>.png` — доля и области.

- Область разницы — открыть оба снимка и картинку-разницу, описать: что сдвинулось или пропало.
- Слепок: пропали заголовки, формы, скрипты или стили (плагин перестал подключать файл) — баг даже без видимой разницы.
- «Одиночные клетки» — шум.

После прогона без blocker / major — «после» становится новой базой: пользователю строкой «база обновлена», файлы скопировать в `qa-base/` (Bash `cp` в `.claude/.state` — это не свой код).

## Серьёзность

Пропал блок, форма, меню; сдвиг каркаса — **major** (форма — **blocker**). Сдвиг ≤ 4 px, другой рендер шрифта — **cosmetic**.
