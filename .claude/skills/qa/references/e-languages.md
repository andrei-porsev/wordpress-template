# E — Языки

Плагин переводов не важен (WPML, Polylang, TranslatePress и другие): QA берёт переводы со страницы.

## Найти переводы страницы

```js
() => ( {
	lang: document.documentElement.lang,
	hreflang: [ ...document.querySelectorAll( 'link[rel="alternate"][hreflang]' ) ].map( ( l ) => [ l.hreflang, l.href ] ),
	switcher: [ ...document.querySelectorAll( 'a[hreflang], a[lang], .wpml-ls a, .lang-item a, .trp-language-switcher a' ) ].map( ( a ) => [ a.hreflang || a.lang || a.textContent.trim(), a.href ] ),
} )
```

- `hreflang` пуст, переключатель есть — баг SEO (**minor**), переводы брать из переключателя.
- Нет ни того, ни другого — список языков: `wp plugin list --status=active --fields=name` (только чтение) → у WPML / Polylang / TranslatePress — языки через WP-CLI (`wp option get` настроек плагина), адрес перевода — по префиксу или домену.
- Языки и способ — записать в `QA.md` → «Настройки», в следующий раз не искать.

## Объём (решение 062)

Основной язык — полный прогон выбранных направлений. Остальные — A на 375 / 768 / 1440 + проверки ниже. C и D на других языках — только если для языка есть свой макет.

## Проверки на каждом языке

1. **Перевод есть:** страница перевода открывается (200, не редирект на основной язык), `<html lang>` верный, видимый текст на нужном языке — прочитать заголовки и кнопки глазами;
   строки основного языка на переводе (непереведённые) — баг со списком строк. Шапка, подвал, формы (подписи, ошибки, плейсхолдеры, письмо-ответ), cookie-баннер, 404 — тоже.
2. **Длина:** немецкий, французский, финский длиннее на 20–40 % — кнопки, меню, заголовки героя, карточки: скрипт обрезки и переполнения из `a-responsive.md`, меню в одну строку не уехало в две.
3. **Шрифт:** символы языка есть в шрифте — нет подмены на системный (кириллица, диакритика `ąčęėįšųūž`, `ß`, `ő`):

```js
async () => {
	await document.fonts.ready;
	const el = document.querySelector( 'h1, h2' );
	const fam = getComputedStyle( el ).fontFamily.split( ',' )[ 0 ].replace( /["']/g, '' ).trim();
	const sample = el.textContent.trim().slice( 0, 40 );
	return { fam, sample, ok: document.fonts.check( `16px "${ fam }"`, sample ) };
}
```

   `ok: false` или скриншот показывает другой рисунок у отдельных букв — **major**.
4. **Переключатель** ведёт на перевод **этой же** страницы, а не на главную; на странице без перевода — понятное поведение (решение в `QA.md`).
5. **Форматы:** даты, валюта, числа (`1 000,50` / `1,000.50`), телефон (`+49 …`) — по языку или по решению в `QA.md`.
6. **RTL** (арабский, иврит): `dir="rtl"`, зеркальные отступы, иконки-стрелки.
7. **SEO языка:** `hreflang` взаимные (A ссылается на B и B на A) и с `x-default`, `title` и `description` переведены, slug — по решению сайта.

## Качество перевода

Не оценивать как переводчик. Явная ошибка (машинный перевод с бессмыслицей, перевод не того смысла кнопки) — **minor** с пометкой «проверить носителю».

## Серьёзность

Страница перевода не открывается / ведёт на другой язык — **major**. Непереведённые строки в интерфейсе, обрезка от длины, подмена шрифта — **major**. Форматы, `hreflang` — **minor**.
