# Документация своих плагинов

Одна папка на плагин, имя папки = слаг плагина. Плагинов может быть несколько.
Внутри слои — только если есть:

```
plugins/
  {plugin-slug}/
    INDEX.md              # точки входа, слои, инструкции фронта и бэка
    front/                # витрина, стили, JS, render.php блоков
      blocks.md
    back/                 # регистрация, REST, CPT, админка
      admin.md
  {another-plugin}/
    …                     # часто только back/, если нет своей витрины
```

Нет слоя — нет папки: плагин без UI не получает `front/`, плагин-только-стили не получает `back/`.

Правила те же, что и для темы: функция / хук / класс → за что отвечает, на языке документации проекта (`INDEX.md` → «Языки работы»),
без копирования тел кода. Инструкции слоя — в INDEX этого плагина, без дубля `CLAUDE.md` и `.claude/rules/`.
Сторонние плагины здесь не документируем.

Этот файл — заглушка, чтобы папка не потерялась в git. Можно удалить после
появления первого реального плагина.
