## Как читать

1. Найти пакет (тема или свой плагин) в таблицах выше.
2. Открыть `themes/<slug>/INDEX.md` или `plugins/<slug>/INDEX.md` — файлы уже разложены на **фронт** и **бэк**.
3. Инструкции слоя — в том же INDEX (или `front/instructions.md` / `back/instructions.md`, если вынесены).
4. Перейти по ссылке в «Детали» — какая функция/хук за что отвечает.
5. Исходник — инструмент **Read** (не Shell, не парсер). Поиск — **Grep**, список файлов — **Glob**.
