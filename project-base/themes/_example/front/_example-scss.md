# Пример детализации фронта

> Шаблон. Агент создаст реальные файлы в `themes/<слаг>/front/` при «построй структуру».  
> Этот пример можно удалить после первой съёмки.

Файл-источник: `wp-content/themes/theme-child/assets/scss/index.scss`  
Роль файла: точка сборки стилей витрины.

## Партиалы

| Файл | За что отвечает |
|------|-----------------|
| `abstracts/` | Переменные и миксины, CSS не даёт |
| `components/_header.scss` | Шапка |
