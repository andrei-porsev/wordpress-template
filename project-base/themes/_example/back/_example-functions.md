# Пример детализации бэка

> Шаблон. Агент создаст реальные файлы в `themes/<слаг>/back/` при «построй структуру».  
> Этот пример можно удалить после первой съёмки.

Файл-источник: `wp-content/themes/theme-child/functions.php`  
Роль файла: подключение модулей темы и регистрация хуков.

## Символы

| Имя | Тип | За что отвечает |
|-----|-----|-----------------|
| `cltm_setup` | функция | Поддержки темы, меню, thumbnails |
| `cltm_enqueue_assets` | функция | CSS/JS на фронте |
