# Документация своих тем

Одна папка на тему, имя папки = слаг каталога в `wp-content/themes/`.
Тем может быть несколько. Чужой parent не документировать.

```
themes/
  {theme-slug}/
    INDEX.md              # точки входа, слои, инструкции фронта и бэка
    front/                # шаблоны, SCSS, JS витрины
      templates.md
    back/                 # functions.php, inc/, хуки
      functions.md
  {another-theme}/
    …
```

Внутри слои `front/` и `back/` — только если слой есть. Пустую папку не заводить.

Правила те же, что и для плагинов: функция / хук / класс → за что отвечает, на русском,
без копирования тел кода. Инструкции слоя — в INDEX этой темы, без дубля `CLAUDE.md` и `.claude/rules/`.

Этот файл — заглушка, чтобы папка не потерялась в git. Можно удалить после
появления первой реальной темы. Папку `_example/` удалить после первой съёмки.
